# ISO 45001 — textos oficiales por requisito

Deja aquí el **texto oficial** de cada requisito, un archivo por código:
`4.1.md`, `4.2.md`, `4.3.md`, `4.4.md`, `6.1.md`, `8.5.md`, …
(`.md`/`.txt` con el texto pegado, o el `.docx` que se extrae solo).

Estos sobrescriben/complementan la guía común de `normas/comun/`.
Este archivo (NOTA.md) es solo informativo; la carga busca `<codigo>.*`.
