# ISO 37001:2025 — textos oficiales por requisito

Deja aquí el **texto oficial** de cada requisito, un archivo por código:
`4.1.md`, `4.2.md`, `4.3.md`, `4.4.md`, `4.5.md`, …
(`.md`/`.txt` con el texto pegado, o el `.docx` que se extrae solo).

La edición vigente es la **2025 (2ª edición)**; el requisito 4.2 incorpora el
literal c) («cuáles de esos requisitos se abordarán mediante el sistema de
gestión antisoborno») y el cambio climático pasa al cuerpo normativo.

Estos archivos están excluidos por `.gitignore`: el texto ISO tiene derechos de
autor. Este archivo (NOTA.md) es solo informativo; la carga busca `<codigo>.*`.
